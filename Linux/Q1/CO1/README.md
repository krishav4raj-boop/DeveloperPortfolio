# Q1 — Linux Fundamentals (CO1)

This folder contains evidence and documentation for **Question 1 (CO1)**: demonstrating foundational Linux command usage, safe system inspection, and structured documentation.

## Contents

| File | Purpose |
| :--- | :--- |
| [linux_commands.md](linux_commands.md) | Detailed guide for 23 essential Linux commands (syntax, realistic examples, expected output, and practical use cases). |
| [system_profile.md](system_profile.md) | Command-based system profile template showing how to capture OS, kernel, CPU, memory, disk, user, directory, and timestamp details on a Linux machine. |
| [commands.sh](commands.sh) | Safe, non-destructive Bash script that prints live Linux environment diagnostics when run on Linux or WSL. |

## How to Run `commands.sh` (on Linux / macOS / WSL / Git Bash)

```bash
chmod +x commands.sh
./commands.sh
```

## Notes on Genuine Evidence

- No system output in [system_profile.md](system_profile.md) has been fabricated.
- Run the listed commands (or `./commands.sh`) on your own Linux environment (Ubuntu, WSL, or lab terminal), paste the real output into [system_profile.md](system_profile.md), and save terminal screenshots inside `Screenshots/Linux/`.

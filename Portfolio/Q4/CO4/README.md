# Q4 — Developer Portfolio, Resume, Roadmap & LinkedIn (CO4)

This folder contains career readiness and professional ecosystem documentation for **Question 4 (CO4)**.

## Contents

| File | Purpose |
| :--- | :--- |
| [resume.md](resume.md) | ATS-friendly beginner developer resume source in Markdown using clearly marked personal placeholders. |
| [resume.pdf](resume.pdf) | Formatted PDF version generated directly from the resume structure. |
| [learning_roadmap.md](learning_roadmap.md) | Structured 4-stage roadmap (Foundation, Next, Intermediate, Advanced) with projects and outcomes. |
| [linkedin_setup.md](linkedin_setup.md) | Step-by-step instructions and copy-ready templates for setting up a beginner developer LinkedIn profile. |
| [linkedin_evidence_checklist.md](linkedin_evidence_checklist.md) | Checklist of real screenshots to capture after updating your personal LinkedIn account. |

## Important Reminder

All personal placeholders (`[YOUR FULL NAME]`, `[YOUR EMAIL]`, `[YOUR GITHUB URL]`, etc.) must be replaced with your real details before final submission. After updating [resume.md](resume.md), regenerate [resume.pdf](resume.pdf) so both files match.
